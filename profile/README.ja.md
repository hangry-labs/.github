# 🧪 Hangry Labs

**自分で管理するハードウェア上で動かせるようにパッケージ化した、ローカルファーストのAIとオープンソフトウェア。人類とナゲットの力のために。**

Hangry Labsは、実用的なセルフホスト型AIシステム、自動化、ダッシュボード、標準仕様、クリエイター向けツールを開発しています。難しい部分をまとめ、使いやすいインターフェースを提供し、現実のトレードオフを正直に説明することで、高機能なソフトウェアを実行、理解、接続、保存しやすくします。

製品ガイド、実際のサンプル、インストール支援は、[Hangry Labsソフトウェアカタログ](https://hangrylabs.app/ja/software)から確認できます。

だって、ただ動いてほしいだけの時もあります。  
12体の依存関係の悪魔を召喚し、Python環境に週末を捧げたいわけではありません。

---

## ⚡ ツールを選んですぐに開始

[ソフトウェアカタログ](https://hangrylabs.app/ja/software)では、新しいHangry Labs UIとパッケージ構成への更新が完了したアプリケーションを紹介しています。何かをダウンロードする前に、各アプリケーションを比較し、実際の音声サンプルを試聴できます。

Dockerベースの音声ツールには、それぞれ対話式インストールガイドがあります。OS、ハードウェア、ダウンロードサイズ、リリース系列、イメージレジストリ、ネットワーク公開範囲について6つの短い質問に答えると、環境に合った1本のコマンドが生成され、各手順も分かりやすく説明されます。回答はブラウザ内だけに保持され、サーバーには送信されません。

プロジェクトを選んで **インストールヘルプ** を開き、コマンド作成という寄り道はウィザードに任せてください。

## 🌍 Hangry Labsが存在する理由

現代のAIツールは強力ですが、その多くはホスト型サービス、見えないインフラ、消えてしまうモデルリンク、複雑なセットアップ儀式、外部アカウントに依存しています。

Hangry Labsは、より自立した方法を選びます。

- ローカル環境または自分で管理するインフラ上でツールを実行する
- プロンプト、音声、文字起こし、文書、画像を非公開に保つ
- 明確なDockerコマンドと妥当な初期設定を提供する
- 実用的な場合はモデルと依存関係を同梱する
- 人が使うブラウザインターフェースと、アプリケーション向けの文書化されたAPIを提供する
- ハードウェア要件、測定結果、制限事項を正直に公開する
- アップストリームへのクレジット、ライセンス、リンクを保持する

理想的な最初の体験は、次のようなものです。

```text
docker run ...
```

そして、そのまま動く。

いつも完璧とは限りません。依存関係の火災とはまだ戦っています。それでも、目指す方向はここです。

## 🛠️ 開発方針

### ローカルファースト、プライバシーを標準に

データは身近な場所に置くべきです。Hangry Labsのプロジェクトは、機密性の高い入力を他社のクラウドへ送らず、自分のマシンやサーバー上で動作することを目指します。

### 実用的な範囲で同梱

完全版Dockerイメージには、モデル資産、ランタイム依存関係、アプリケーション本体を含めることができます。すべてを同梱すると現実的でない場合は、安定した永続データボリュームを利用する小型イメージを提供できます。

目標は最小イメージ競争ではなく、信頼性です。パッケージの変更やモデルリンクの消失で壊れる小さなイメージより、来年も動く少し大きなイメージの方が役に立つことがあります。

### オープンなインターフェース

人には分かりやすいブラウザインターフェースが必要です。アプリケーションや自動化には、文書化されたHTTP API、役に立つ状態エンドポイント、予測可能な挙動が必要です。

OpenAI互換APIが適している場合は、実用的な互換性の基準として採用しつつ、製品固有の有用な機能も利用できるようにします。

### 制限を正直に伝える

高速なモデルは機能範囲が狭い場合があります。高性能なモデルは、より多くのメモリと忍耐を必要とする場合があります。ベンチマークにはハードウェアと設定を明記し、互換性ガイドでは何を測定したのかを明確にします。

魔法の煙はありません。少しだけ劇的なエンジニアリングの現実があるだけです。

### アップストリームへの敬意

多くのHangry Labsプロジェクトは、優れたオープンソースの研究とソフトウェアを基盤にしています。アップストリームへのクレジットとライセンスを見える形で保持し、どの部分がアップストリーム由来か、Hangry Labsがパッケージ、インターフェース、配布、検証に何を追加したかを文書化します。

## 🚀 長期的な方向性

Hangry Labsは今も、有用な寄り道のためのラボです。より広い方向性には、次のローカルファーストなツールが含まれます。

- AIコンパニオンと音声インターフェース
- 記憶と知識のシステム
- セルフホスト型ダッシュボード
- プライベートな自動化
- クリエイターツール
- ゲームと配信のユーティリティ
- モデル配信と可観測性
- 音声マークアップと相互運用性
- 高速で再現可能なAI推論

目指しているのは、人が実行、理解、変更、接続、保存できるツールの集合です。

すべてをクラウドのサブスクリプションにする必要はありません。使う人自身が所有できるものも必要です。
